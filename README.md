# Problem 1
Define the function mul_rationals which takes in two rational numbers and returns a rational number which is the product of the two inputted numbers.

# Problem 2
Define the function div_rationals which takes in two rational numbers and returns a rational number which is the division of the two inputted numbers.

# Problem 3
Define the function print_rationals which takes in a rational number and prints the number in human-readable notation.  For example, print_rationals(rational(3,4)) will print 3/4.

# Problem 4
Define the function rationals_are_equal which takes in two rational numbers and returns True if the rational numbers are mathematically equivalent and False otherwise.  For example, rationals_are_equal(rational(3,4), rational(30,40)) returns True while rationals_are_equal(rational(3,4), rational(3,5)) returns False.
